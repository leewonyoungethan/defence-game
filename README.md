# 🏰 디펜스 게임

브라우저에서 바로 즐기는 타워 디펜스 게임입니다.

**▶ 플레이: https://leewonyoungethan.github.io/defence-game/**

## 방법
- 아래에서 타워를 고르고 풀밭을 클릭해 설치
- 설치된 타워를 클릭하면 업그레이드 / 판매
- 총 100 웨이브, 5웨이브마다 👑 보스 등장 (100웨이브 클리어 시 승리)
- `🔁 연속` 버튼을 켜면 웨이브가 자동으로 이어짐

| 타워 | 가격 | 특징 |
|---|---|---|
| 🏹 화살탑 | 50 | 빠른 연사 |
| 💣 대포탑 | 100 | 범위 폭발 |
| ❄️ 얼음탑 | 80 | 감속 |
| ⚡ 레이저탑 | 150 | 장거리 광선 |
| 🧪 독탑 | 90 | 지속 독 피해 |
| 🌩️ 번개탑 | 130 | 연쇄 번개 |
| 🔥 화염탑 | 110 | 주변 전체 화상 |
| ⛏️ 금광 | 120 | 웨이브마다 골드 |
| 🎯 저격탑 | 200 | 가장 강한 적 저격 |
| 🔫 기관총탑 | 120 | 초고속 연사 |
| 🚀 미사일탑 | 220 | 유도 미사일 대폭발 |
| 🌨️ 눈보라탑 | 140 | 주변 냉기 파동 |
| 🎇 산탄탑 | 130 | 여러 적 동시 공격 |

| 🌪️ 회오리탑 | 170 | 적 넉백 |
| 🌀 블랙홀탑 | 250 | 강력 감속 |

## 적
| 적 | 등장 | 특징 |
|---|---|---|
| 🦇 박쥐 | 6웨이브 | 날아다님, 주변 공격 타워(화염/눈보라/망치/블랙홀)에 안 맞음 |
| 💚 힐러 | 8웨이브 | 주변 적 체력 회복 |
| 🫧 분열 | 12웨이브 | 죽으면 2마리로 분열 |
| 🛡️ 기사 | 15웨이브 | 받는 피해 40% 감소 |
| 👻 유령 | 20웨이브 | 가끔 투명해져 공격 불가 |
| 💪 트롤 | 25웨이브 | 체력 자동 회복 |
| 💨 돌진 | 30웨이브 | 가끔 초고속 돌진 |

배속: x1 → x2 → x3 → x5 → x10 (버튼 또는 `F` 키)

단축키: `1~0` 타워 선택, `Space` 다음 웨이브, `U` 업그레이드, `P` 일시정지, `Esc` 취소

치트 코드: 상단 `🔑 코드` 버튼 → `방탄유리` 입력 시 돈 무한
