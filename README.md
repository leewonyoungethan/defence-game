# 🏰 디펜스 게임

브라우저에서 바로 즐기는 타워 디펜스 게임입니다.

**▶ 플레이: https://leewonyoungethan.github.io/defence-game/**

## 방법
- 아래에서 타워를 고르고 풀밭을 클릭해 설치
- 설치된 타워를 클릭하면 업그레이드 / 판매
- 5웨이브마다 👑 보스 등장

| 타워 | 가격 | 특징 |
|---|---|---|
| 🏹 화살탑 | 50 | 빠른 연사 |
| 💣 대포탑 | 100 | 범위 공격 |
| ❄️ 얼음탑 | 80 | 적 감속 |
| ⚡ 레이저탑 | 150 | 장거리 강타 |

단축키: `1~4` 타워 선택, `Space` 다음 웨이브, `U` 업그레이드, `P` 일시정지, `Esc` 취소

치트 코드: 상단 `🔑 코드` 버튼 → `방탄유리` 입력 시 돈 무한
